# Getting help

- **Questions or bugs in a specific project:** open an issue in that repository.
- **About CRASR, collaborations, or analytical services:** see the [center's website](https://crasr.artsandsciences.baylor.edu) or [contact page](https://crasr.artsandsciences.baylor.edu/contact-us).
- **Overview of our tools and projects:** [crasr.github.io](https://crasr.github.io).

CRASR code is shared openly as research software. We help where we can, but response times vary and support isn't guaranteed.
