# Security

## Reporting a problem

Please **don't open a public issue** for security problems. Instead:

- Use **Report a vulnerability** under the repository's **Security** tab, if it's enabled, or
- Contact the repository maintainers privately.

This includes accidentally exposed credentials, API keys, or connection strings, and any data that shouldn't be public. Include the repository, file, and commit if you can.

We'll acknowledge reports as soon as we can and fix confirmed problems promptly.

## Scope

Most CRASR repositories are research code and tools maintained by a small team. Unless a repository says otherwise, only the latest version on the default branch is supported.
